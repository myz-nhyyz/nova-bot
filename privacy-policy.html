Nova is a standalone browser interface created to present the automation features represented by the supplied Discord bot code in a Liquid Glass-style web workspace.

1. Data stored by this website

The current static build stores only demo preferences and demo workspace data in your browser using localStorage. Examples include operation records, event participant counts, UI preferences, logs and masked sample key metadata.

2. No Discord token collection

This frontend does not contain, request, or transmit your Discord bot token. API secrets should not be embedded in client-side HTML, JavaScript or browser storage when deploying a real integration.

3. External services

The supplied bot code references Discord and AI services. This standalone website does not call those services. The “AI”, “Ban Guard”, “War Ping”, “Backup” and related actions are local simulations until a secure backend is connected.

4. Browser storage

Because demo state is stored locally, clearing site data or browser storage can remove it. No account system is included in this static build.

5. Security

For a production deployment, keep Discord tokens, Gmail credentials, API keys and administrative passwords server-side and use authenticated HTTPS API endpoints from the frontend. The supplied Python source itself loads sensitive values from environment variables rather than hard-coding the bot token.

6. Contact

Privacy questions can be sent to anhbao27072011@gmail.com. Community support is available in the Nova support server.

This is an independent web interface inspired by Apple’s Liquid Glass design language. It is not an official Apple product or service.
