1. Scope

This policy applies to the Nova web workspace and its optional Python backend proxy. The browser interface provides an iOS 26-inspired Liquid Glass presentation of the Discord bot features represented by the supplied Nova source.

2. Browser data

The static interface stores workspace preferences and demo state locally in your browser using localStorage. Depending on how you use the interface, this can include operation records, event counts, UI preferences, activity logs and chat history displayed in the browser.

3. AI chat requests

When the backend is running and an API key is configured, messages submitted in AI Studio are sent from the Nova backend to the configured Gemini API using the selected Gemini model setting. The backend adds Nova's feature knowledge, language/persona settings and recent conversation context to the request. The provider's own privacy, logging, retention and processing practices may apply.

4. API keys and secrets

The website is designed so the real AI API key remains server-side. Do not put Discord bot tokens, API keys, Gmail credentials or administrative passwords inside index.html, browser storage, or public repositories.

5. Discord data

The standalone web interface does not automatically log into Discord or perform Discord moderation actions. A separate production integration would need authenticated backend endpoints and should only access data and actions authorized by the operator.

6. Data retention

Browser-stored demo state remains until it is cleared by the user or overwritten by the site. Server-side AI request retention is determined by the operator's deployment and the configured AI provider; this website does not make a blanket retention promise for the provider.

7. Security

Use HTTPS in production, restrict backend access, protect environment variables, apply authentication/rate limits, and review Discord/API permissions before exposing administrative actions.

8. Contact

Privacy questions can be sent to anhbao27072011@gmail.com. Community support is available in the Nova support server.

Nova is an independent project. The interface is inspired by Apple’s iOS 26 Liquid Glass visual language and is not an official Apple product or service.
